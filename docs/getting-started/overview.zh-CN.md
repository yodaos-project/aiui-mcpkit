# 先了解：MCPKit 能帮你做什么

[English](overview.md) | 简体中文 · [学习路线](../README.zh-CN.md)

假设你让助手展示一份旅行计划，随后打开一个小应用：你可以切换日期、收藏地点，再决定把哪些选择发回对话。MCPKit 帮你构建这样的界面，并把它打包给 AI 客户端使用。

你用 JavaScript、页面标签和样式编写一个 **AIUI 应用**，MCPKit 生成客户端调用工具和显示界面所需的文件。还没接入助手时，也可以先在浏览器中开发。

## 先看看能做什么

仓库提供旅行规划、专注计时、数据看板、活动预约、Counter 和业务示例。可以先看[真实运行时截图](../../README.zh-CN.md#让用户直接操作-ai-工具)，也可以直接[在本地运行 Counter](quickstart.zh-CN.md)。

这些示例可以操作，但使用演示数据。活动确认不会真实预约或付款；专注计时器在 View 打开时运行，隐藏时暂停。

## 先记住三个部分

| 名称 | 负责什么 |
| --- | --- |
| **AIUI** | 你编写的应用格式，包括 `app.json`、`.ink` 页面、JavaScript 和素材。 |
| **Ink** | 执行页面代码、绘制界面的运行时。MCPKit 会打包它的 WebAssembly 版本。 |
| **MCPKit** | 构建工具，把应用与 MCP 服务、交互视图一起打包。 |

一个 `.ink` 文件可以同时包含页面标签、JavaScript 和样式。了解基础 HTML、CSS、JavaScript 会更容易上手；AIUI 有自己的组件与 API，教程会在用到时介绍。

## 每次只增加一种能力

1. **先看到界面：** 在浏览器里运行本地预览。
2. **改成自己的样子：** 修改按钮，再创建一个只有两个源文件的应用。
3. **让助手打开它：** 声明工具参数，再连接客户端。
4. **返回有用的结果：** 添加服务端函数，之后再按需把界面状态接入对话。

每一步都有可运行的结果，可以随时停下来实践。按[学习路线](../README.zh-CN.md)前进即可，不必先读完全部指南。

## 后面会遇到的词

- **工具（tool）：** 助手可以调用的操作，例如给 `open_counter` 传入一个起始计数。参数用 JSON 表示。
- **宿主 / 客户端（host/client）：** 启动服务的助手应用。显示交互界面还需要支持 MCP Apps。
- **视图（View）：** 应用界面在宿主中打开的一份实例。
- **stdio：** 客户端通过本地进程的输入输出通信。这是一种连接方式，不是网页地址。
- **处理函数（handler）：** 你编写的业务工具服务端函数。Worker 是可选的执行方式，在进阶指南中介绍。

## 浏览器预览与客户端各能做什么

浏览器预览使用真实 Ink/WASM，提供启动参数，并在源码修改后刷新。对话消息、助手工具调用和服务端业务结果，需要支持的宿主或测试环境。先用预览开发界面，之后再学[连接客户端](../guides/clients.zh-CN.md)。

MCPKit 当前生成本地 stdio 服务。需要了解 HTTP 部署、协议细节和各客户端的验证情况时，再查[兼容性说明](../reference/compatibility.zh-CN.md)。
